📜 1. Sejarah Singkat UML (1995)

Sebelum tahun 1995, konsep Berbasis Objek (OO) sangat populer namun diimplementasikan dalam berbagai notasi berbeda oleh para pengembang (seperti Booch, Coad, OMT, OOSE, SOMA).

Pada tahun 1995, Rational Software menyatukan 3 pakar utama industri (Three Amigos: Grady Booch, Ivar Jacobson, dan James Rumbaugh) untuk menciptakan standar notasi tunggal: UML (Unified Modeling Language).

Tujuan Utama UML

Menyediakan kosakata umum (common vocabulary) dari istilah-istilah objek dan teknik pemodelan diagram yang cukup kaya untuk memodelkan proyek pengembangan sistem dari tahap analisis hingga implementasi.

📐 2. Dua Kategori Utama UML Diagram

Kategori Diagram UML Tujuan & Fungsi Pemodelan Contoh Diagram Termasuk
1. Structure Diagrams (Diagram Struktur) Merepresentasikan data dan hubungan statis (static relationships) dalam sistem informasi. Class Diagram, Object Diagram, Package Diagram, Component Diagram, Deployment Diagram, Composite Structure Diagram, Profile Diagram.
2. Behavior Diagrams (Diagram Perilaku) Menggambarkan hubungan dinamis (dynamic relationships) dan perilaku objek dari waktu ke waktu. Menyajikan requirement fungsional. Use-Case Diagram, Activity Diagram, Sequence Diagram, Communication Diagram, State Machine Diagram, Timing Diagram, Interaction Overview Diagram.

💡 3. Poin-Poin Penting & Cara Menghafal

📌 Poin Utama UAS

  • UML diciptakan oleh Rational Software pada tahun 1995.
  • Structure Diagram = Hubungan Statis (Contoh: Class Diagram).
  • Behavior Diagram = Hubungan Dinamis (Contoh: Use-Case Diagram, Activity Diagram, Sequence Diagram).

🧠 Jembatan Keledai

"Statis-Structure / Dinamis-Behavior" ➔ Statis = Structure Diagram, Dinamis = Behavior Diagram.

✍️ 4. Contoh Soal UAS & Pembahasan

Soal 1 (Pilihan Ganda)

Manakah di antara diagram berikut yang tergolong ke dalam kategori Structure Diagram di UML?

A. Use-Case Diagram
B. Sequence Diagram
C. Class Diagram
D. Activity Diagram

Jawaban: C. Class Diagram

Pembahasan: Class Diagram menggambarkan hubungan statis antar-kelas sehingga termasuk Structure Diagram. Pilihan A, B, dan D adalah Behavior Diagram.
